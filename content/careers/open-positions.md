# Open positions

Each role lives in its own markdown file under `content/careers/jobs/`.

- **Add a role:** create `{id}.md` with frontmatter (`id`, `title`, `description`, `department`, `location`, `type`, `order`, optional `postedDate`, `requisitionId`) and the full job description in the body.
- **Remove a role:** delete the file.

The careers page and `/careers/[id]` detail routes are generated automatically from those files.
