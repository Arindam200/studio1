## What you will do

You will help Studio1 build and test cloud AI demos, agent workflows, and technical examples for internal products and client work.

- Build practical demos using AWS, cloud AI services, LLM APIs, tools, and agent workflows.
- Try new agentic frameworks, SDKs, orchestration tools, and cloud AI patterns quickly.
- Create example repos, small prototypes, and setup notes that developers can run or understand.
- Test AI-agent workflows around retrieval, tool use, automation, evaluation, integrations, or developer productivity.

## What we are looking for

You should be comfortable with AWS basics, curious about GenAI systems, and able to show proof that you can build.

- You have used AWS before and understand core cloud concepts such as IAM, APIs, Lambda, storage, deployments, or serverless workflows.
- You have explored AI agents, LLM apps, RAG, automation, cloud AI services, or agentic frameworks.
- You can learn new SDKs, docs, frameworks, and cloud services without needing every step explained.
- You can build clean prototypes and explain the implementation clearly.
- You care about developer experience: setup steps, repo structure, docs, examples, and what can break.
- Past projects, GitHub repos, demos, cloud experiments, AI-agent apps, or technical writing are strong proof.

You will get room to build hands-on AI and cloud experiments around developer products, agents, and modern AI infrastructure. This is a good fit for someone who wants practical AWS and GenAI project experience, not only theory.
